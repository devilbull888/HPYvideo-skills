# 镜头语义设计 + 真实素材层

第二集复盘结论：画面问题的根因不是动效，而是**镜头按模板选、没按句意选**，以及**全片没有真实素材**。本文件规定两件事：每句话怎么决定画面（第 1 节），真实素材怎么找、怎么合规、怎么做动效（第 2、3 节）。

---

## 1. 逻辑关系 → 镜头形式（强制对照表）

先判断这句话的逻辑关系，再从本表选镜头形式。**一种关系只能用它对应的形式**，不得借用别的关系的模板。

| 逻辑关系 | 典型句式 | 应该用的镜头形式 | 禁止 |
|---|---|---|---|
| 引入/钩子 | "你最近一定见过……" | 本集核心对象（梗词、LOGO、人物、截图）**占画面最大面积**，0.5 秒内出现 | 核心词做成角落小贴纸；只放标题文字 |
| 列举 | "A、B、C 都……" | 并列网格/卡片墙，每项**带真实素材**（品牌→LOGO，人物→头像，作品→封面） | 编号 1/2/3（除非真有顺序）；⊘ 等带否定含义的图标 |
| 单个数据 | "超过三十八亿" | 大数字 + 数据所属对象的 LOGO/图标；数字从目标值的 60% 起滚 | 数字从 0 滚（会出现"约 0 亿"） |
| 部分占整体 | "一千来部 / 二十二万部" | 占比格/占比条，**必须标出整体是什么、部分是什么** | 用于两个不同口径或不同平台的数据 |
| 并列对比 | "抖音 38 亿，小红书 1 亿" | 左右/上下并列，各自带平台 LOGO，各自单位 | 画进同一个占比格（会被理解成 A 占 B 的百分比） |
| 因果/流程 | "因为……所以……"、"先……再……" | 箭头流程、线条绘制、形变（4/6 号手法） | 无箭头的平铺列表 |
| **纠正（不是A，是B）** | "不是AI赢了，是人借AI的嘴" | **A 出现 → 被划掉/翻面/碎裂 → B 替换上来成为主体**；或用一个视觉比喻同时表达 A 和 B 的真实关系 | **≠ 不等号**（≠ 表示两者不相等，不是纠正） |
| 转折/揭示 | "荒诞的是……""但真正……" | 画面先建立表象，再翻转/拉远揭示真相（例如镜头拉远，露出流水线） | 只换一行文字 |
| 引用证据 | "新华网报道……""论文里写……" | 原始文件/截图 + 荧光笔高亮被引用的那句 + 来源角标 | 只写"来源：xx"小字 |
| 叙述剧情/案例 | "良心老板用好料，黑心同行打价格战" | 先交代"这是 X 的剧情"，用分镜格/剧照 1→2→3 讲 | 无上下文的贴纸，观众不知道是谁的情节 |
| 群体声音 | "网友都在说……""大家借它说……" | 仿真评论区（头像、昵称、点赞数、越刷越多），或多个气泡汇聚成一句 | 一张孤立的小贴纸 |
| 金句/结论 | "AI量产台词，人量产意义" | 用一个视觉比喻把两半关系画出来（左：同一张台词卡被复印成一摞；右：每张卡被网友写上不同的话），文字是配角 | 两张文字贴纸平摆 |
| 提问/CTA | "你最近说……了吗？评论区聊聊" | 数字人 + 问题大字 + 仿评论输入框 | — |

**写镜头表时的三条硬规则：**
1. "观众要看懂什么"写成一句完整的话，例如："网友才是让这句话火起来的人，AI 只是提供了台词。"
2. 每个镜头至少提供一项字幕之外的信息：真实素材、证据原件、结构关系或视觉比喻。
3. 句子里的**核心实体**（品牌、人物、平台、作品、机构）默认要有真实素材。没有的话，在镜头表里写明原因，例如"找不到合规素材，改用 AI 示意图"。

**排版硬规则：** 主体元素放在画面中部（y 400–1300），面积不小于画面的 40%。不要把所有内容都挤在顶部 1/3，下半部又空着。

## 2. 真实素材：来源、版权分级、登记

用户确认的尺度是：**低风险 + 中风险 + 适当引用**。获取方式是：能自动下载的由模型下载，下载不到或版权拿不准的列成清单交给用户。没有真实素材时，允许使用 **AI 示意图，但必须标注**。

### 2.1 来源和等级

| 等级 | 素材 | 优先来源 | 使用条件 |
|---|---|---|---|
| 低 | 公有领域/CC0 照片和文件（历史人物、老论文、政府公开文件） | Wikimedia Commons（看文件页的 License 栏）、各国政府/机构官网、arXiv（看论文许可证） | CC BY 系列要署名，写进画面角标或视频简介 |
| 低 | 品牌图标 SVG | Simple Icons（simpleicons.org，CC0 收录。但商标权仍属品牌方，按"中"级规则使用） | 不改形、不改色（可单色化），不暗示合作 |
| 中 | 官方 LOGO、官方海报/官方微博配图 | 品牌官网的"媒体资料/品牌资源"页、官方微博/公众号 | 指名性使用：只用于说明"这个品牌做了什么"；不改形；不放在像代言的位置；不和贬义文字直接叠在一起 |
| 适当引用 | 新闻标题截图、剧照、短视频截帧、他人评论截图 | 原报道页面、原作品 | 依据著作权法第 24 条：只为评论或说明问题、只截必要的小部分、必须注明出处。**评论截图要把头像和昵称打码**，或改用自绘仿真评论 |
| 示意 | AI 示意图 | 模型写提示词，用户用自己的生图工具生成 | 角标写"AI 示意图"；不能画真实人物、真实品牌物料、仿真截图 |
| 不用 | 来路不明的 LOGO 站、壁纸站、表情包、他人肖像照（非公众人物，或公众人物的私人场合照） | — | — |

**真实人物照片**：公众人物优先用 Wikimedia Commons 上的公有领域或 CC 照片。在世人物如果找不到合规照片，改用"名字 + 职位卡 + 原话引用"，不要从新闻图库扒图。

### 2.2 自动下载的做法（模型执行）
- Wikimedia Commons：用 API 拿文件元数据和原图地址，许可证字段写进 manifest：
  `https://commons.wikimedia.org/w/api.php?action=query&titles=File:<名>&prop=imageinfo&iiprop=url|extmetadata&format=json`
- Simple Icons：`https://cdn.simpleicons.org/<slug>` 获取 SVG（slug 先在 simpleicons.org 查）；或者确认 `node_modules` 里有没有 `simple-icons` 包。
- 官网 LOGO：用 webfetch 找到官网媒体资料页再下载；找不到就交给用户。
- 下载后执行 `sha256sum`，写进 `data/assets_manifest.json`，同时生成 `out/assets_contact.jpg` 缩略图联系表给用户确认。
- 中文品牌（例如蜜雪冰城、费大厨）大多不在 Simple Icons 里，通常要去官网或官方微博找，或者列给用户。

### 2.3 manifest 格式
```json
{
  "file": "public/assets/logo/mixue.png",
  "sha256": "...",
  "kind": "logo | photo | document | screenshot | still | ai_illustration",
  "entity": "蜜雪冰城",
  "source_url": "https://...",
  "rights_holder": "蜜雪冰城股份有限公司",
  "basis": "official_logo_nominative | CC0 | CC-BY-4.0 | public_domain | fair_quote_art24 | ai_illustration",
  "attribution": "（CC BY 时必填）",
  "used_in": ["S04"],
  "fetched_at": "2026-10-24",
  "fetched_by": "model | user"
}
```

### 2.4 处理规范
- 位图统一转成 PNG/JPG，长边不超过 2000px。LOGO 优先用 SVG。
- 截图类素材只裁出必要的部分，再用荧光笔或描边框高亮引用的那一句。
- 带白底的 LOGO 放在白色圆角卡上（贴纸风格天然适合），不要硬抠图。
- 照片统一做一次轻调色（饱和度 -10%，加暗角）以融入品牌白底，**不改变内容**。

## 3. 素材类镜头组件（需要新写，放在 `src/templates/assets/`）

下面这些组件第二集还没有，第三集开始按需实现。实现后在本节标注"已实现"和参考路径。

| 组件 | 用途 | 动效做法（Remotion） |
|---|---|---|
| `LogoReveal` | 品牌出场 | 白卡弹入（spring）→ LOGO 从遮罩中揭示（`clipPath` inset 动画）→ 一道扫光（斜向线性渐变 `translateX`）；配音效 pop + confirm |
| `LogoWall` | 列举多个品牌 | 网格依次弹入，锚点对准旁白里每个品牌名；每格下面写一行"做了什么"（例如"出了不烧心联名海报"） |
| `PhotoKenBurns` | 人物或场景照片 | 缓慢推拉加平移（scale 1.0→1.08）；人物名牌从底部滑入；轻暗角 |
| `DocHighlight` | 论文、报告、新闻原件 | 文件整页出现 → 镜头推近到引用段落 → 荧光笔从左到右涂抹（矩形宽度动画，颜色用品牌蓝 30% 透明度）→ 来源角标 |
| `ScreenshotCallout` | 新闻标题、热搜、话题页 | 截图放在手机框里 → 描边框圈出关键信息 → 引线连到一句解读 |
| `CommentFeed` | 网友/群体声音 | 自绘仿真评论 UI（灰色圆形头像、打码昵称、点赞数），按锚点逐条上滑；数量越刷越多，最后汇聚成一句大字 |
| `StoryPanels` | 剧情/案例 | 2–4 格分镜（剧照或 AI 示意图）+ 每格一句台词；先显示"这是 X 的剧情"标题条 |
| `StrikeReplace` | 纠正"不是A是B" | A 以正常大小出现 → 红色删除线划过（宽度动画）+ 轻微抖动 → A 缩小变灰退到上方 → B 放大成为主体；音效用 error → confirm |
| `ZoomOutReveal` | 转折/揭示 | 先特写表象（一张台词卡）→ 镜头拉远（scale 3→1），揭示真相（流水线上成百上千张同样的卡） |
| `PlatformStat` | 平台数据 | 平台 LOGO 在上，大数字从 LOGO 下方"长"出来；两个平台并列时左右各一套 |

**实现要点：**
- 素材一律用 `staticFile("assets/...")` 引入，用 Remotion 的 `<Img>`（等待加载完成，避免渲染出空帧），不用 `<img>`。
- 所有素材镜头组件都接收 `source` 参数，自动渲染来源角标；`basis` 为 `ai_illustration` 时自动加"AI 示意图"角标。
- 照片和截图的推拉只用 `transform`，不要用会触发重排的属性，以免渲染变慢。

## 4. 示例：第二集「不烧心」按新规则应该怎么做（供参考，不代表已实现）

| 句子 | 逻辑关系 | 观众要看懂什么 | 画面方案 | 素材 |
|---|---|---|---|---|
| S01 你最近刷评论，一定见过这三个字，不烧心 | 钩子 | 这期讲的是全网刷屏的"不烧心" | "不烧心"三个大字占半屏，四周飘起评论气泡；数字人小窗在下方 | 自绘评论 UI |
| S02 这班上得不烧心…… | 群体声音 | 这句话已经被网友用到各种场景 | `CommentFeed`：上班、养猫、看视频三类评论逐条刷出，点赞数在涨 | 自绘评论 UI（头像和昵称打码） |
| S03 抖音播放超过三十八亿，小红书破一亿 | 并列对比 | 两个平台都很火 | `PlatformStat` 左右并列：抖音 LOGO + 38.5 亿次，小红书 LOGO + 1.1 亿次 | Simple Icons：抖音（tiktok）、小红书（xiaohongshu，需确认 slug） |
| S04 蜜雪冰城、旺仔、费大厨都下场玩梗 | 列举 | 大品牌也跟着玩这个梗 | `LogoWall` 三格，每格 LOGO + 一行"做了什么"；如有官方玩梗海报，作为适当引用缩略图放进去 | 官网 LOGO / 官方微博海报（适当引用） |
| S05 荒诞的是，这句话是AI流水线批量生产的 | 转折/揭示 | 这句流行语其实来自 AI 批量做的短剧 | `ZoomOutReveal`：特写一张"不烧心"台词卡 → 拉远，露出传送带上成排同样的卡 | 自绘，或 AI 示意图 |
| S06–S07 同一套模板，良心老板……不烧心 | 叙述剧情 | 这是这批 AI 短剧的固定剧情套路 | `StoryPanels` 三格：老板用好料 → 同行打价格战 → 顾客说"不烧心"；标题条"AI 短剧的固定剧情" | 剧照（适当引用）或 AI 示意图 |
| S08 换个菜名就能再拍一部 | 列举 | 同一个模板只换菜名 | 同一个分镜模板盖章四次，每次换菜品图：猪脚饭/热干面/烧饼/鱼丸 | 菜品照片（CC 素材）或自绘图标 |
| S09 新上线短剧二十二万部，破亿只有一千来部 | 部分占整体 | 量产很多，真正火的极少 | 占比格标明"整体 = 22.19 万部新短剧"，1055 部高亮成一小撮（约 0.5%） | — |
| S10 真正把这句话捧火的，不是AI，是网友 | 纠正 | 火的原因是网友，不是 AI | `StrikeReplace`：AI 图标 + "AI" 被划掉 → 网友头像群放大成为主体；数字人在下方 | 自绘 |
| S11 大家借它说一个朴素的诉求，别糊弄我 | 群体声音 | 网友用它表达"别糊弄我" | 评论气泡从四面八方汇聚 → 合成一句"别糊弄我"大字 | 自绘评论 UI |
| S12 所以不是AI赢了，是人借AI的嘴，说出了自己的话 | 纠正 | AI 只是传声筒，说的是人自己的话 | 一个 AI 喇叭图标，喇叭里冒出的气泡全是网友的话（"别糊弄我""要真材实料"）；"AI 赢了"被划掉放在角落 | 自绘 |
| S13 AI量产台词，人量产意义 | 金句 | AI 负责数量，人负责意义 | 左：同一张台词卡被复印成一摞；右：每张卡被写上不同网友的话。文字作为标题 | 自绘 |
