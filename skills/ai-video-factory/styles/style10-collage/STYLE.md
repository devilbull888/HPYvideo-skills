# 10 号风格「拼贴」复用库

来源：第八集 buffer（`D:\OPC\sandbox\buffer-20261110`，`final_125x.mp4` 验收发布）沉淀。新集首次用 10 号风格时从这里起步。

> 调性：纸元素被"摆上去"的手工感，适合政策解读、对比论证、流程拆解类选题；不适合需要照片真实感或重情绪叙事的选题（ep8 教训：硬凑照片会语义错位）。

| 文件 | 说明 |
|---|---|

## 底与板块

- 1080×1920；纯色纸底 + 纸纹理 + 暗角，**不用报纸纹**。
- 一个论点一种纸色，换色本身就是转场信号。ep8 三块：政策米白 / 数据灰蓝 / 个人米黄。
- 板块切换：纸滑入盖屏转场，滑入那张纸的色取**下一板块**的底色；板块内用 6f 交叉淡化。

## 元素语法

- 撕纸卡：seed 化不规则 clip-path + 白边衬 + drop-shadow + ±3° 旋转；图钉随卡落定后再砸下（晚 ~4f）。
- **外部素材准入链**：CC0/PD 照片候选（逐张审语义，每槽位 3–4 选 1）→ 对不上就降级 Iconify 语义图标贴纸（MDI/Material Apache-2.0、Tabler MIT）。全部统一白边撕纸卡 + 图钉，禁 AI 人脸。**禁止按标题关键词盲下素材不审图**。
- **禁用元素**：胶带装饰（显脏，ep8 全删）；用黑块当"鸿沟"等抽象隐喻（表意不明——抽象概念优先用纸的物理动作表达：撕 / 断 / 接，`RipGap` 参考实现）。
- 抽象隐喻优先用纸动作：鸿沟 = 撕开的缝；断桥 = 中段断开的纸桥；衔接 = 纸桥接回。

## 贯穿装置：钩子轴

底部胶片齿孔撕纸条，节点 = 问题链各问，当前节点高亮、换镜时标记滑动；兼做进度条 + 结构图。**轴不抖**。

## 动效系统（三层，编舞不是抖动）

| 层 | 内容 |
|---|---|
| 入场 | 拍板 slap 三变体按 seed 分（下落 / 侧滑 / 弹出）；元素按锚点错峰；数字滚动窗口拉长到整段（455% 滚 ~1.5s@1×）；手绘元素用 strokeDashoffset"画出来" |
| 阵风 | 默认换镜触发一次（React context 下发镜头起点，元素 0–8f 错峰）；**同方向**吹（随机方向 = 抖动）：图钉卡以钉为支点单摆衰减 ±6.5°（`transformOrigin` = 钉点）、固定卡微颤 ×0.35、自由纸片右移 ~26px + 轻倾 |
| 常驻 | 逐元素相位定格抖动，1× 下 8 次/s、±1.5px |

**锚点豁免**：字幕 / 钩子轴 / 数字人卡 / IP 角标不抖不晃（IP 角标随阵风摆）。

## 排版纪律（ep8 教训固化）

- 一屏 **1 焦点 + ≤4 支撑元素**；超了先删不是先挤。
- 安全区先落区再摆位：字幕 1400–1560 / 钩子轴 1608–1660 / IP 角标区 / 主视觉区；右侧留防爆边（ep8 "受影响的人"标签出屏一次）。
- 字幕禁短尾孤页：分页时短尾并入上页或放宽行宽重排（ep8 修法）。
- **"0.5 秒读懂"审图**：每镜渲一帧静图，半秒内能说出它表达什么才过；ep8 靠这一步定位了 3 处碰撞 + 1 处弱表意。
- 数字人窗内元素先验碰撞：数字人卡占下方 ~y1330 起，上方元素底边压不住的标签要整体上移。

## 速度判定

不预设倍速。判据：**1.5× 下可读物成片驻留不足的镜占比高就降回 1.25×**（量化线用时序审计那条 ≥1.2s）。ep8 全片条款 + 数据密度高，1.5× 初审被退，1.25× 验收通过。口语化轻量片才优先试 1.5×。

## 实测成本（WSL node + CPU MuseTalk）

4892 帧（1×，约 163 秒）整片渲染 ~6 分钟；数字人 3 段 862 帧@24fps 约 1.9 小时（8–13s/帧 + 每段 ~1 分钟模型加载）；封面静帧 ~20 秒。
