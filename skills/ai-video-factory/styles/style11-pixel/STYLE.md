## 用法

1. **整片包在 `<Pix>` 里**：所有坐标按 270×480 逻辑像素写，用 `ipx()` 取整，保证放大后仍是整像素。不要在 1080 尺度上直接摆元素，否则像素会糊成半格。
2. **10fps 抽帧**：动画时间统一走 `qf(f)`（30fps → 10fps 台阶），运动才有像素游戏的顿挫感。平滑插值会破坏风格。
3. **全部用 DOM 写，不用 SVG**：`<svg>` 里的 `<image>` 在截图前不加载，`<div>` 放进 `<svg>` 会消失。图块一律用 `PixImg`（div + img + overflow 裁切 + `imageRendering: pixelated`）。
4. **Kenney 图块间距是 17px，不是 16px**：`tile(col,row)` 已按 17px 步长、16px 图块算。选图块前先渲一张对照表（ep6 的 `out/probe_tiles.png`），按编号挑，不要凭感觉猜坐标。
5. **场景图**：可以直接裁 `Sample_fantasy.png` 这类示例场景（ep6 用城墙围合当宫殿）。素材"像不像"只靠图块拼不够时，宁可换比喻，不要用色块冒充美术（ep6 keyframes_v1 被否的原因）。
6. **角色动画**：经典 2 帧 bob 行走 `bob = qf(f) % 2`，配合 `walkX` 匀速位移；同屏多个角色把 bob 相位错开一帧（`bob(f+1)`）。角色"做事"（走过关卡、指向按钮）比站桩好得多。
7. **字幕像素化**：`<Captions pixel />`，游戏对话框式（黑底、白边框、红角标、FusionPixel 字）。ep6 v3 用普通字幕，被用户指出和像素场景割裂，v4 改成像素版后统一。
8. **全片字体白名单**：场景字、气泡字、字幕全部用 FusionPixel。ep6 v4 的 S08 气泡用了平滑矢量字体，独立审核判"中"。
9. **扫描线**：`<Scanlines op={0.08} />` 叠在最上层，透明度不超过 0.1，否则字会发灰。

## 踩过的坑（ep6）

- **第 0 帧文字钩太小**：v4 只有约 64px、宽 37%，顶部 40% 空屏。像素字在 270 逻辑尺度下要写到 ≥28 逻辑像素（×4 ≈ 112px）才满足 SKILL 的 110px 指标。
- **IP 角标对比度**：暗红字压在深蓝底 `#1a1c2c` 上几乎看不见。深色底的风格，角标要用浅色字或加浅色底衬，交付前在 180px 缩略图下确认可读。
- **字幕框压按钮**：像素对话框比普通字幕高，内容区底边要留出余量（ep6 S10 双按钮被压住约 1/3）。
- **真人数字人卡和像素世界不搭**：ep6 只在开头和结尾用了 P01、P10 两段。其余时间要不要数字人、怎么和像素画面衔接，下次用这个风格时再单独评估。
